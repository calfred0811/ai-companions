✦ About AI Companions

✦
AI Companions
v1.0 — built with ❤️
Create your own AI characters, chat with them, and build stories together. Each companion has their own personality, appearance, and memory. Your data stays on your device — nothing is uploaded.
📖 Slash Commands:
/tokens — check daily tokens remaining
/story — set the story/scenario
/intro — set character's opening message
/image [prompt] — generate an image
/capture [note] — save a moment
/moments — view captured moments
/ebook — export story as text file
/persona — edit your persona for this character
/history — view full conversation history
/retry — regenerate last AI reply
/addchar — add another character to the story
/edit — edit character's profile & appearance
/about — this screen
🔑 Go to ⚙️ Settings to add your free Groq API key for real AI replies. Without a key, the app runs in demo mode.
